# ReelLoop Studio 4.6 Alpha

Ruckelfreie Wiedergabe-Iteration.

## Änderungen
- Countdown verschwindet zuverlässig nach dem Einzähler.
- Keine permanenten `currentTime`-Sprünge mehr.
- Keine laufenden `playbackRate`-Korrekturen mehr.
- Gemeinsamer Start aller Videospuren.
- Nur noch seltene Driftprüfung an der Loop-Grenze.
- Native Videoloops für flüssigere Android-Wiedergabe.
